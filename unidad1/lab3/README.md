# ejercicios 
# include: 
- Sirve para incluir librerías o archivos externos en tu código, dándote acceso a funciones ya escritas (como printf para imprimir en pantalla).
# define:
- Sirve para crear constantes o atajos (macros). Reemplaza automáticamente un texto por un valor en todo el programa antes de compilar.
# if:
- Sirve para la compilación condicional. Permite incluir u ocultar bloques de código según se cumpla o no una condición antes de compilar.
# line
- Sirve para cambiar manualmente el número de línea y el nombre del archivo que el compilador utiliza para reportar errores o advertencias. Su uso principal es en herramientas que generan código automáticamente para hacer que los errores apunten al archivo fuente original y no al generado.
