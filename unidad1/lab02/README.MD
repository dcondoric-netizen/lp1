# Laboratorio02
# El procedimiento que realice en mi codigo de c++ es;
- primero leemos un número y revisamos que no sea 0
- segundo vemos si el número tiene 2 o más dígitos 
- tercero descartamos usando % 10 para sacarle el último dígito y / 10 para borar
- cuarto luego guardamos y sumamos esos dígitos en suma.
- quinto convertimos el número en el resultado de la suma num = sum y repetimos el proceso hasta que quede una sola cifra
- sexto y por ultimo ostramos en pantalla el número final de un solo dígito.
